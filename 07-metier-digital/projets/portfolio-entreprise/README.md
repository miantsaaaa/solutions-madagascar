# Portfolio Entreprise - V7.1
## Probleme Madagascar
Tu as construit 6 outils qui marchent, mais personne ne les voit.
Si tu ne montres pas ton travail, personne ne peut te trouver.

## Solution
Une page portfolio qui presente ton entreprise, tes outils, tes preuves.
100% sur Redmi, en HTML simple, hors-ligne.

## Comment lancer
Ouvre index.html dans ton navigateur (Chrome sur Redmi).

## Fonctions V7.1
- Presentation : qui tu es, ta vision pour Madagascar
- Tes 6 outils avec preuves (scores, chiffres)
- Contact : GitHub
