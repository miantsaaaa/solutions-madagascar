# 01 - Genie Logiciel + BDD - VERSION MOBILE / REDMI

## Mission ici
Creer des outils qui tournent SUR ton Redmi, dans Termux, sans PC.
Des outils que tu lances avec 1 commande, meme avec 10% de batterie.

## TYPES d'outils MOBILE a creer ici
- Utilitaires CLI pour Termux : renommer, trier, organiser tes fichiers du telephone
- Gestion de tes cours / notes / fichiers sur le telephone
- Suivi depenses / budget en Ariary, en local, sans internet
- Petite BDD SQLite sur le telephone pour tes donnees perso
- API locale sur le telephone qui sert tes autres domaines

## D'abord quotidien sur 【entity-Redmi¦canonical_name=Redmi】
Ex : organiser tes photos / PDFs de cours, liberer de l'espace, suivre tes depenses.

## Ensuite pro sur Redmi
Ex : petite appli de gestion complete qui tourne sur un telephone, avec BDD + tests.
Un outil pro qui marche meme avec une petite connexion, c'est ca la valeur a Madagascar.

## Regle Mobile
1 outil = doit marcher sur 【entity-Redmi¦canonical_name=Redmi】, sans PC, sans gros internet.
1 outil = 1 commande simple, pas 10 etapes.
1 outil = doit marcher meme si tu fermes Termux et tu reviens.
