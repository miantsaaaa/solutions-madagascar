# 02 - Admin Systeme + Reseau - VERSION MOBILE / REDMI

## Mission ici
Surveiller, proteger et entretenir TON Redmi et TON Ubuntu dans Termux.
Ton telephone est ton serveur.

## TYPES d'outils MOBILE a creer ici
- Surveillance batterie : niveau, temperature, consommation
- Surveillance stockage : ce qui prend de la place sur 256 Go
- Surveillance reseau mobile : 4G, WiFi, vitesse, coupures
- Sauvegarde auto de tes dossiers Termux / cours vers un dossier safe
- Nettoyage auto : logs, cache, fichiers temporaires de Termux
- Check securite : ports, services, mises a jour de Termux / Ubuntu

## D'abord quotidien sur 【entity-Redmi¦canonical_name=Redmi】
Ex : alerte batterie faible, nettoyage stockage, sauvegarde de tes cours avant de dormir.

## Ensuite pro sur 【entity-Redmi¦canonical_name=Redmi】
Ex : monitoring complet d'un petit serveur mobile, sauvegarde avec restauration, rapport d'etat.

## Regle Mobile
Toujours tester sur TON Redmi, TON reseau.
Toujours logger, meme si la 4G coupe.
Jamais d'outil qui vide la batterie en 1h.
